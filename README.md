# Леонид Богачук — Product Manager · бизнес-визитка

Одностраничный сайт-резюме: ключевые результаты в цифрах, карьерный путь, кейсы, принципы работы и форматы сотрудничества. Сделан как статическая страница на одном HTML-файле — без сборки и зависимостей.

## Запуск

Просто откройте `index.html` в браузере или поднимите любой статический сервер:

```sh
# например, через Python
python -m http.server 8080
# или npx
npx serve .
```

## Дизайн-система

Все токены вынесены в `:root` внутри `index.html`:

- **Цвета** — `--bg`, `--card`, `--ink`, `--muted`, `--line`, `--accent`, `--accent-deep`, `--on-ink`, `--on-accent` и др.
- **Типографика** — `--font` (Inter) и `--mono` (JetBrains Mono), подключены через Google Fonts.
- **Радиусы, отступы, контейнер** — `--radius`, `--gap`, `--container`, `--space` / `--space-mobile`.

Стиль — «редакционная бизнес-визитка»: тёплый светлый фон, единственный синий акцент, моноширинные ярлыки `[ 01 ]`, номера-индексы у секций.

### Компоненты

- Навигация (sticky + blur) и progress-bar
- Hero с фото и статусом
- Карточки результатов с анимацией счётчиков, графиков и кольца (IntersectionObserver)
- Аккордеон кейсов и FAQ (с `aria-expanded`)
- Таймлайн карьеры, сетка навыков, блоки «подойду / не подойду»
- Тёмные блоки: AI, форматы работы, контакты

## Доступность и адаптив

- Контраст текста проходит WCAG AA
- Полная поддержка `prefers-reduced-motion`
- `:focus-visible` для клавиатурной навигации
- Адаптив: 1 колонка → 2 (≥640px) → до 4 (≥900px)

## Технологии

HTML + CSS + ванильный JS, без зависимостей. Сайт работает без интернета (кроме подключения шрифтов Google Fonts).
